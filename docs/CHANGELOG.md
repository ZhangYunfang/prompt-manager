# 变更记录

本项目的界面改版记录。打包产物与发版资产见 GitHub Releases。

## 1.6.2

**Windows 启动报错修复**
- 换成文件夹版：解压后进 `PromptManager` 文件夹双击 `PromptManager.exe`
- 原因：单文件版每次启动都要把 `PySide6\Qt6Core.dll`（10 MB）等依赖从 exe 里解压到临时目录，杀软拦截或受限的临时目录会让这一步失败，报 `Failed to extract PySide6\Qt6Core.dll decompression resulted in return code -1`。文件夹版没有任何运行时解压步骤，这类报错结构上不会再出现
- 同时关闭 UPX 压缩（同属这类启动解压异常的常见诱因）
- Linux 同步改为文件夹版（`tar.gz` 解压得到 `PromptManager/`）

## 1.6.0

**我的提示词**
- 列表右键新增「修改标题和标签…」：改已收藏条目的标题与标签，不调用 AI
- 修改对话框复用「添加收藏」：预填现有标题、现有标签逐个勾选（默认全选），可勾掉，也可在下方补自定义标签
- 标题可清空（列表退回显示正文首行）；选中与自定义标签自动去重保序
- 保存后立刻落盘，并按当前搜索词重刷列表（可能进出结果集）
- 悬停提示同步为「右键修改标题/标签、复制或删除」

## 1.5.0

**字号层级**
- 修正单位混用：小标签用 px、按钮走 13pt，同屏差 6px，导致「标签偏小、按钮偏大」
- 小标签 11→12px、副标/计数 10→11px、按钮 ≈17.3→13px，按钮/标签比值从 1.57 收到 1.08

**整体字号**
- 设置页新增「整体字号」：`小` / `大` 每档 10%，范围 80%~140%，另有「恢复默认」
- 点击立即生效（边调边看），保存才落盘；取消会把字号还原成打开时的值
- 编辑器正文（等宽字体）跟随缩放；所有字号统一走 `_f()` / `px()` 两个换算函数

**我的提示词**
- 左键**单击**即加载到编辑区（原来是双击），悬停提示与「关于」文案同步
- 新增搜索框：标题、标签、正文任意命中即可，大小写不敏感

**其它**
- 文档新增 `docs/diagrams/`：桌面端架构图（含生成源 candidate.json）
