# 变更记录

本项目的界面改版记录。打包产物与发版资产见 GitHub Releases。

## 1.3.0

**主体风格色盘**
- 页头新增方形色盘，8 种主体风格：青紫（默认）/ 蓝 / 紫 / 绿 / 黄 / 橙 / 粉 / 灰
- 悬停显示风格名，点击即时切换全部强调色；选中项加描边；选择写入 `settings.json`

**底色随风格联动**
- 换风格时整套底色一起换：背景 / 卡片 / 二级卡片 / 输入框 / 边框 / 滚动条
- 按强调色色相重新着色、明度层次不动，文字对比度不退化（黑夜 12.5:1、白天 14.9:1）
- 默认青紫风格保留手调的 `#1a2236` / `#EEF2F8`；黑夜为深色，白天为近白带极淡色相、卡片纯白

**历史记录**
- 「历史记录」标题后新增刷子按钮：一键清空全部历史（弹确认框；列表为空时置灰）

**其它**
- `+` 号改为自绘两条线，水平垂直精确居中（不再受字体基线影响）
- 应用图标底部加白色圆角底，深色 Dock 上不再看不清

## 1.2.0

**面板布局**
- 「收藏夹」改名「我的提示词」并移到左侧，历史记录移到右侧
- 「我的提示词」标题后新增 `+`：把编辑区内容存进我的提示词
- 编辑区「收藏」前新增「新增」：清空编辑区并定位到输入框
- 右键菜单「取消收藏」改为「从我的提示词移除」

**图标**
- `make_icons.py` 先合成白色圆角底（Big Sur 圆角比例、12% 内边距）再导出各档尺寸

## 1.1.1

- 换用新的应用图标（源图 `icon-source.png`）

## 1.1.0

- 新增黑夜 / 白天双主题，黑夜底色 `#1a2236`
- 新增 `ui/theme.py`：DARK / LIGHT 配色令牌、QSS、`as_panel()`、`variant()`
- 界面改为卡片式布局：品牌栏 + 三栏面板 + 2px 流动强调线
- 新增 macOS / Linux 启动脚本 `run.sh`、Windows 启动脚本 `run.bat`
- 新增 GitHub Actions 三平台自动打包（`.github/workflows/build.yml`）
